# Next Ware ERP

WholesaleFlow is a cross-platform desktop ERP application designed for small and medium-sized wholesale and distribution businesses.

## Core Modules

- Company Management
- Users & Roles
- Products
- Customers
- Suppliers
- Warehouses
- Inventory
- Purchasing
- Receiving
- Sales Orders
- Picking
- Packing
- Shipping
- Reports
- Audit Logs

## Technology

### Desktop
- Tauri
- React
- TypeScript

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate

### Database
- PostgreSQL
- Flyway

### Infrastructure
- Docker
- GitHub Actions
